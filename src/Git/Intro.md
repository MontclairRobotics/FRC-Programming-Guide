# Git & GitHub

Git is the industry standard system for code version control. It tracks changes to our code as we edit, permitting more complicated ways of saving and managing code. GitHub is a fancy GUI (graphical user interface) to access the tools of Git without needing CLI (command line interface), and stores code in the cloud. Using Git & GitHub, we can track everyone’s contributions from their device, see where mistakes or bugs may have occured, and revert as neccessary.
